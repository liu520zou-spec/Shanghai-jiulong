## 服务场景与方案
### 新店筹备
适用：独立咖啡馆、茶饮店开业
方案：吧台设计+设备清单+开业原料包+基础培训

### 门店升级
适用：老店改造、菜单焕新
方案：设备更新建议+新品研发+员工再培训

### 多店扩张
适用：连锁品牌3家以上门店
方案：标准化设备配置+区域集采+培训体系搭建

### 政企项目
适用：办公园区、政府机关、4S店
方案：咖啡角设计+设备租赁+定期补货+员工培训
